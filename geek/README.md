# Albert Formatger — Developer Portfolio

> Personal CV/portfolio web built with React.js. Geek/terminal aesthetic inspired by matrix green and CLI interfaces.

---

## Tech Stack

- **React 18** + **Vite 5**
- **CSS3** — custom properties, no frameworks
- **Fira Code** — monospace font

## Features

- Terminal-style UI with matrix green theme
- Typing effect cycling through roles (Hero section)
- Animated skill bars by category
- Git-log style experience timeline
- Embedded interactive Tic Tac Toe game (portfolio project)
- Scanlines overlay effect
- Fully responsive (mobile, tablet, desktop)

## Sections

| Section | Description |
|---|---|
| Hero | Typing effect, terminal widget, quick links |
| About | Bio, avatar, stats |
| Skills | Tech bars + soft skills + software |
| Experience | 8 roles, color-coded timeline |
| Education | Academic background |
| Projects | SoundSheet, HIFI Bridge, Token Liquidity, Tic Tac Toe |
| Contact | Code-style contact info |

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Build

```bash
npm run build
npm run preview
```
